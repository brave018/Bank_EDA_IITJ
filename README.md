# Bank Exploratory Data Analysis (Bank EDA)

This repository contains an Exploratory Data Analysis (EDA) project focused on analyzing banking sector data to identify key customer behaviors, financial indicators, and risk/conversion trends.

---

## 📌 Project Overview

Exploratory Data Analysis (EDA) plays a critical role in the banking and financial sector for risk management, customer segmentation, credit risk assessment, and optimizing marketing strategy.

This project analyzes banking customer datasets to answer key business questions, such as:
- What demographic and financial factors correlate with customer default risk or product subscription?
- How are income, credit balance, age, and loan history distributed across various customer segments?
- Which key features provide the strongest signal for predictive analytics and data-driven decision-making?
